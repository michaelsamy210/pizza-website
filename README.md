# PizzaHup — Modern Dynamic Restaurant Web Application 🍕

A sleek, modern, and fully responsive Single-Page web application designed for a premium pizzeria. This project highlights efficient modern front-end design workflows, clean modular layouts, custom client-side loading states, and elegant view transition architectures.

Live Preview available at: **[michaelsamy210.github.io/pizza-website](https://michaelsamy210.github.io/pizza-website/)**

---

## ✨ Features & Functional Highlights

- **Single-Page Navigation Matrix**: Integrated seamless intra-page smooth scroll telemetry mapping navigation links perfectly across semantic sections (`Home`, `About`, `Menu`, `Contact`).
- **Preloader State Management**: Features a dedicated client-side UI loader interface wrapper (`#loader`) designed to handle temporal asset initialization cycles gracefully before displaying primary layout matrices.
- **Micro-Interaction UI Components**: Configured dedicated interface nodes including floating interaction arrays, grid-aligned menu card arrays, responsive banner layers, and a functional back-to-top execution node (`#topBtn`).
- **Fluid Layout Fluidity**: Built leveraging high-performance utility vectors in **Bootstrap 5**, delivering cross-device structural scaling, flexible alignment clusters, and interactive contact feedback views.
- **Asynchronous Animation Hooks**: Implemented structural visual hooks utilizing dedicated motion layout cues (`.fade-up`) designed to synchronize element scroll reveals cleanly via active script loops.

---

## 🛠️ Built With

- **HTML5**: Semi-semantic components designed for modern structure validity and performance.
- **Bootstrap (v5.3.7)**: Advanced responsive layout frameworks, spacing utilities, grid setups, and element presets.
- **Custom CSS3 Variable Layers**: Assembled fine-tuned aesthetic property definitions, layout colors, and dynamic interaction micro-states.
- **Vanilla JavaScript**: Core DOM event orchestration handlers, scrolling listeners, and interaction state updates.
